# Seed image attribution

These images are used as default photos for the demo catalog (`PizzaImageSeeder`
applies them to any pizza row that has no admin-uploaded image yet). All are
resized/re-compressed copies of freely-licensed Wikimedia Commons photos —
resizing/re-encoding is a permitted modification under both licenses provided
the same attribution and license terms carry over, which this notice does.
